ARTICLE II. SCOPE OF WORK 
2.1 OVERVIEW/BACKGROUND 
a. TWC is procuring the acSoft Inc ServiceNow Power BI plug-in connector.   
b. This ServiceNow Microsoft Power BI plug-in connector is utilized to 
facilitate seamless extraction, transformation, and loading (ETL) of data 
from ServiceNow into Microsoft Power BI.  In addition, this ServiceNow 
Power BI plug-in connector provides a robust, integrated bridge between 
both platforms, allowing TWC to quickly generate comprehensive datasets 
from any ServiceNow table within a single, unified data source. 
2.2 DESCRIPTION OF SERVICES/SCOPE OF WORK/SPECIFICATIONS 
These specifications are being advertised under Section 2155.067 of 
the Texas Government Code. Only bids on items conforming exactly 
to these specifications, which include proposing only the brand 
name(s), make and model number(s) specified, will be considered in 
determining an award.

[page 9]
IFB No. 3202600219 Page 9 of 25 
a. Successful Bidder must provide the acSoft Inc ServiceNow Power BI plug-
in connector. 
b. Successful Bidder must provide key features of the acSoft Inc ServiceNow 
Power BI plug-in connector which include: 
1. The ability to export any ServiceNow tables and fields (including 
Custom tables and fields); 
2. The ability to include any amount of tables and fields to your Data 
Source; 
3. The ability to create any amount of Data Sources (data sets); 
4. No limitations in exported data. To reduce the server load during the 
export process, the application provides the server-side pagination of 
data over the OData protocol (limited to 1.000 rows per page); 
5. Advanced filtering options to manage data selection and export only 
the relevant information; 
6. Robust permission settings and access management for secure data 
sharing; 
7. Dot-walking mechanism for exporting Reference type data, allowing 
easy access and inclusion of fields from related tables; 
8. Incremental refresh support for efficient Power BI reports and 
dashboards updates without reimporting the entire dataset; 
9. Power Query support (merge ServiceNow with other data sources, 
transform data and load it into Power BI Desktop with no-code 
experience); and 
10. Pre-typed data, eliminating the need for manual conversion to target 
types such as integer, boolean, decimal, etc.
